# Templates

Starter applications that are intended to be copied by `agentic create`.

| Template | Description |
|----------|-------------|
| [`chatbot-client/`](chatbot-client/) | Next.js chatbot UI that streams messages through the MongoDB Agentic Platform API |
| [`hello-world-agent/`](hello-world-agent/) | Minimal Daily inspiration assistant with date and memory tools |
| [`insurance-agent/`](insurance-agent/) | Insurance starter with quoting, policy management, claims, optional memory, and human review |
